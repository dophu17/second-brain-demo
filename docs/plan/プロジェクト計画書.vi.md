### 1.2 Lộ trình phát triển & Mục tiêu từng Phase

Dự án áp dụng công cụ AI Coding giúp giảm 50% thời gian lập trình, hoàn thành trọn vẹn cả 3 Phase trong vòng **1 tháng (22 ngày làm việc)**:

- **Phase 1 (MVP / PoC Core Engine - 10 ngày làm việc)**: 
  - LINE Bot Webhook (FastAPI) nhận tin nhắn văn bản & voice note.
  - Xử lý Voice-to-Text bằng **Faster-Whisper STT**.
  - Parser Python (`python-frontmatter` + `re` + `networkx`) bóc tách YAML Frontmatter và Wiki-links `[[...]]`.
  - Hermes Agent (Nous Research ChatML) tự động sinh Metadata & Wiki-links, tạo file `.md` trong Vault.
- **Phase 2 (Graph RAG & Vector Search - 6 ngày làm việc)**:
  - Tích hợp Vector Database (ChromaDB) + thuật toán duyệt đồ thị `networkx` (Wiki-Link Graph Traversal).
  - Tối ưu hóa phản hồi tri thức không bị mất ngữ cảnh (Hybrid RAG Search).
- **Phase 3 (Multi-Persona, LINE UX & Sửa Note cũ - 6 ngày làm việc)**:
  - Hoàn thiện kịch bản System Prompt đóng vai góc nhìn quản trị: CEO, CFO, CMO, Second Brain Alter-Ego.
  - Cho phép người dùng ra lệnh bằng giọng nói/chat hoặc bấm nút Flex Message để **chỉnh sửa/nối tiếp nội dung note cũ**.
  - Nghiệm thu & Release toàn bộ hệ thống.
