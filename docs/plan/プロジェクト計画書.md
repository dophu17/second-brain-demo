### 1.2 プロジェクト目的・スケジュール目標

AIコーディングツールの活用により開発工数を大幅に圧縮し、全3フェーズを **約1ヶ月（22営業日 / 実装22人日）** で完遂します。

- **Phase 1（MVP / PoC Core Engine - 10営業日 / 10人日）**: 
  - LINE Bot Webhook（FastAPI）によるテキスト・音声メッセージ受信。
  - **Faster-Whisper STT** による音声テキスト変換。
  - Pythonパーサー（`python-frontmatter` + `re` + `networkx`）によるFrontmatter YAMLとWiki-links `[[...]]` の抽出。
  - Hermes Agent（Nous Research ChatML）による自動Frontmatter/Wiki-links付与、およびVault内 `.md` ファイルの自動生成。
- **Phase 2（Graph RAG & Vector Search - 6営業日 / 6人日）**:
  - Vector DB（ChromaDB）と `networkx` によるWiki-link Graph Traversal（グラフ探索）の統合。
  - 文脈を逃さないハイブリッド検索（Hybrid Graph RAG）の実現。
- **Phase 3（Multi-Persona、LINE UX & 過去メモ編集 - 6営業日 / 6人日）**:
  - 経営視点ペルソナ（CEO、CFO、CMO、Second Brain Alter-Ego）のSystem Prompt完成。
  - LINEからの過去メモ編集・追記機能の実装。
  - 全体結合テストおよび本番受入（UAT）。
