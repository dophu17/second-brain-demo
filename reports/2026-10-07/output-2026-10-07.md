### 2. Chi tiết Kết quả Chạy thử Kịch bản Demo (E2E Test Scenario)

#### 📝 Kịch bản thử nghiệm:
> **Người dùng gửi tin nhắn thoại / văn bản từ LINE Bot:**
> *"Hôm nay tôi vừa họp với [[Kenichi]] về tiến độ [[Dự án 2]]. Kenichi yêu cầu hoàn thành báo cáo tài chính trước thứ 6."*

#### ⚙️ Tiến trình xử lý của hệ thống:
1. **[Tầng 1 & 2] LINE Bot $\rightarrow$ FastAPI Webhook:**
   - Webhook tiếp nhận HTTP POST payload từ LINE, xác thực chữ ký an toàn.
   - Chuyển dữ liệu âm thanh/văn bản đến `processing_pipeline`.

2. **[Tầng 3] Processing Pipeline (Parser & Graph Engine):**
   - `obsidian_parser` sử dụng Regex bóc tách các liên kết 2 chiều: `[[Kenichi]]` và `[[Dự án 2]]`.
   - Trích xuất tự động YAML Frontmatter: `tags: [meeting, project_2]`, `date: 2026-10-07`, `author: Executive`.
   - `graph_engine` (NetworkX) tạo các Nodes & Edges, tính toán incoming links (Backlinks) kết nối note mới với các file note cũ `Kenichi.md` và `Dự_án_2.md`.

3. **[Tầng 4] AI Agent Core (Hermes Agent Tool Calling):**
   - Hermes Agent tiếp nhận prompt ChatML, phát sinh lệnh `<tool_call>`:
     ```xml
     <tool_call>
     {"name": "create_note", "arguments": {"title": "2026-10-07_Hop_voi_Kenichi", "folder": "10_Projects", "tags": ["meeting", "kenichi", "project_2"], "content": "Kenichi yêu cầu hoàn thành báo cáo tài chính trước thứ 6."}}
     </tool_call>
     ```

4. **[Tầng 5] Obsidian Vault Storage:**
   - Hệ thống tự động khởi tạo file Markdown chuẩn: `vault/10_Projects/2026-10-07_Hop_voi_Kenichi.md`.
   - Trả phản hồi **LINE Flex Message** với thẻ UI đẹp mắt kèm nút bấm nhanh "Sửa Note" hoặc "Thêm Chi Tiết".
