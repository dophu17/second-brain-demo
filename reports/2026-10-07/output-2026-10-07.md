### 2. Cấu trúc File Codebase Demo & Docker Setup

```
second-brain-demo/
├── Dockerfile                   # Python 3.10-slim base image cho FastAPI App
├── docker-compose.yml           # Compose service mapping port 8000 & volume mount
├── requirements.txt             # fastapi, uvicorn, python-frontmatter, networkx, requests
├── app/
│   ├── main.py                  # FastAPI Webhook & REST Server Entrypoint
│   ├── config.py                # Cấu hình OLLAMA_BASE_URL (http://host.docker.internal:11434)
│   ├── api/
│   │   ├── webhook.py           # LINE Bot Webhook Handler
│   │   └── demo.py              # REST API Endpoint kiểm thử trực tiếp
│   └── services/
│       ├── obsidian_parser.py   # Bộ bóc tách YAML Frontmatter & [[Wiki-links]]
│       ├── graph_engine.py      # NetworkX Knowledge Graph Engine
│       └── hermes_agent.py      # Ollama Local ChatML & Tool Calling Service
├── vault/                       # Obsidian Vault Local Directory (mount vào Docker)
└── scripts/
    └── test_demo.py             # Script kiểm thử tự động E2E Demo Scenario
```
