```

      │

```

#### Phân công Chi tiết:
1. **Độ (PM - Project Manager):** Quản lý tiến độ chung, làm việc với JP/khách hàng, chịu trách nhiệm cơ chế báo cáo định kỳ cho team Việt Nam (1h/ngày - tổng 22h cho toàn bộ 3 Phase).
2. **Khôi (Dev - LINE & Voice STT):** Phát triển Server FastAPI Webhook (`line-bot-sdk-python`), tích hợp pipeline dịch giọng nói **Faster-Whisper STT** và thiết kế giao diện thẻ **LINE Flex Messages** + tính năng chỉnh sửa note cũ từ LINE.
3. **Phú (Dev - Obsidian Data Layer & Graph Engine):** Phát triển module Python Parser (`python-frontmatter` + `re`), thiết kế cấu trúc Obsidian Vault, quản lý Đồ thị Tri thức bằng **`networkx`** và tích hợp Vector DB (ChromaDB) cho Graph RAG.
4. **An (Dev - AI Agent & Multi-Persona):** Phát triển cơ chế **Hermes Agent Tool Calling** (cú pháp ChatML `<tools>`, `<tool_call>`), khai báo OpenAPI Tools, tích hợp Graph RAG Traversal và thiết kế bộ System Prompts Multi-Persona (CEO, CFO, CMO, Second Brain).
